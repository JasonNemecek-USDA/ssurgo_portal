# Support

## How to get help

- For bugs: open a **Bug report** issue.
- For enhancements: open a **Feature request** issue.
- For docs improvements: open a **Documentation request** issue.

Use the repository issue templates to provide enough detail for triage.

## Response expectations

This repository is maintained on a best-effort basis unless otherwise stated by maintainers. Response times can vary based on maintainer availability and priorities.

## What to include

When asking for help, include:

- Environment details (OS, Python version, tool versions)
- Reproduction steps
- Expected behavior vs. actual behavior
- Logs or screenshots (redacted as needed)

## Security and sensitive reports

For vulnerabilities or sensitive issues, follow [SECURITY.md](SECURITY.md) and avoid public disclosure.
