# Contributing to SSURGO Portal

Thank you for contributing.

## Getting started

1. Read [`README.md`](README.md) and [`docs/README.md`](docs/README.md).
2. Open an issue describing the bug, improvement, or documentation change.
3. Keep pull requests focused and small.

## Development standards

- Prefer clear, maintainable changes.
- Update documentation when behavior, workflows, or standards change.
- Add or update tests when code changes include testable behavior.

## Pull request checklist

- [ ] Scope is focused and related to one issue
- [ ] Documentation updated (if applicable)
- [ ] Tests updated or rationale included
- [ ] Security and operational impact considered
