# Code of Conduct

## Our commitment

We are committed to providing a respectful, inclusive, and harassment-free environment for all participants.

## Expected behavior

- Be respectful and constructive.
- Assume good intent and collaborate in good faith.
- Focus feedback on ideas and implementation details, not individuals.
- Use welcoming and professional language.

## Unacceptable behavior

- Harassment, discrimination, or intimidation.
- Personal attacks, insults, or trolling.
- Publishing private or sensitive information without permission.
- Any conduct that would be inappropriate in a professional environment.

## Reporting concerns

If you experience or observe behavior that violates this Code of Conduct, report it through repository maintainers using the support and security contacts documented in [SUPPORT.md](SUPPORT.md) and [SECURITY.md](SECURITY.md).

## Enforcement

Maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that do not align with this Code of Conduct.
