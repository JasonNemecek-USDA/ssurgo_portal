# SSURGO Portal v1.0.0.118 Must-Have Only Plan

## Purpose
This is the condensed execution plan for .118 with strict priority order.
Only must-have items are included.
All non-critical enhancements are deferred.

## Scope Locked for .118
1. National-scale performance and completion reliability for US + HI + AK + PR + territories/outlying areas.
2. Stall-proof execution with retries, checkpoints, and resume.
3. Complete error capture and diagnosable failures.
4. Usable long-run experience (clear status, safe controls).
5. USDA CEC OCIO-aligned security and release gates.
6. Dual release: CMD retained and EXE added.
7. PKG packaging model with install.com and executable workflow.

1. Completion KPI: 100% selected areas accounted for as success or categorized fail.

5. Security KPI: Scan-clean, signed, and policy-compliant artifacts.
6. Deployment KPI: Software Center pilot install/uninstall succeeds with detection rules.
