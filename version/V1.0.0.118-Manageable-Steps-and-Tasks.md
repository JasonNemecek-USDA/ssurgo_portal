# SSURGO Portal v1.0.0.118 Manageable Steps and Tasks

## Goal
A practical .118 execution list broken into small, manageable task batches.
Each batch is intended to be completed and validated before moving to the next.
Primary SLA target for this release cycle: full national manifest p95 <= 30 minutes across managed Python runtime fallback paths.

## Working Rule
1. Only work one batch at a time.
2. Each batch must pass its exit check.
3. No skipping ahead unless current batch is complete.

## Definition of Done for Every Batch
- Code builds and runs.
- No new critical lint/runtime errors.
- Target behavior is verified with a quick test.
- Notes are added to release tracking.

## KPI Targets for .118
1. Full accounting KPI: every selected area is success or categorized fail.
2. Resume KPI: interrupted run resumes without redoing completed areas.
3. Speed KPI: full national manifest p95 <= 30 minutes with no increase in failure rate.
4. UX KPI: no perceived freeze during long runs.
5. Security KPI: signed, scan-clean artifacts with compliance evidence.
6. Deployment KPI: Software Center pilot success for EXE package.
