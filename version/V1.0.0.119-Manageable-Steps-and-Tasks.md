# SSURGO Portal v1.0.0.119 Manageable Steps and Tasks

## Goal
A practical .119 execution list broken into small, manageable task batches.
Each batch is intended to be completed and validated before moving to the next.
Primary SLA target for this release cycle: full national manifest p95 <= 30 minutes across managed Python runtime fallback paths.

## Working Rule
1. Only work one batch at a time.
2. Each batch must pass its exit check.
3. No skipping ahead unless current batch is complete.

## Definition of Done for Every Batch
- Code builds and runs.
- No new critical lint/runtime errors.
- Target behavior is verified with a quick test.
- Notes are added to release tracking.
