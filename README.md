## GitHub workflow templates

- Pull request template: `.github/pull_request_template.md`
- Issue forms: `.github/ISSUE_TEMPLATE/`

## Developer scaffolding

- `.editorconfig`
- `.gitattributes`
- `.pre-commit-config.yaml`
- `Makefile`

These files provide practical repository-level defaults and guidance. Organization-level controls (for example branch protections/rulesets) are configured by maintainers in GitHub settings.
